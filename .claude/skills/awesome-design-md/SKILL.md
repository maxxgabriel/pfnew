# Awesome DESIGN.md

From github.com/VoltAgent/awesome-design-md (MIT, commit 3b60532, fetched 2026-10-19). Each file in
`design-md/<site>.md` describes one site's design language in plain markdown.

How to use it here:

- `ls design-md/` to see the sites; read only the one or two you need (they are long).
- Take **craft** from them (how they scale type, set spacing rhythm, separate surfaces, treat a
  button), never their identity: this portfolio's rule is *original, not copied*. Don't reproduce a
  brand's palette, logo, wordmark, layout or copy.
- The film's own look (ink, paper, the red spark, the act styles) and the owner's rules in
  `CLAUDE.md` and `docs/OWNER_INSTRUCTIONS.md` always win over anything in these files.
